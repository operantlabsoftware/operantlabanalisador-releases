## Download

Acesse a [página de releases](https://github.com/operantlabsoftware/operantlabanalisador-releases/releases/latest) para baixar a versão mais recente.

| Sistema | Arquivo | Instruções |
|---|---|---|
| **Windows 10/11** | `Instalador_OperantLab_Analisador_vX.Y.Z.exe` | Execute o instalador e siga os passos |
| **Linux (AppImage)** | `OperantLabAnalisador-vX.Y.Z-x86_64.AppImage` | Dê permissão de execução e abra |
| **Linux (tar.gz)** | `OperantLabAnalisador_linux_vX.Y.Z.tar.gz` | Extraia e execute |

O Analisador também vem incluído no [OperantLab™](https://github.com/operantlabsoftware/operantlab-releases). Esta é a versão standalone, que avisa e se atualiza sozinha quando sai uma versão nova.
